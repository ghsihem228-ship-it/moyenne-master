# Third-party libraries

- jsPDF 4.2.1: https://github.com/parallax/jsPDF — MIT, included in www/vendor/jspdf-LICENSE.txt.
- jsPDF AutoTable 5.0.9: https://github.com/simonbengtsson/jsPDF-AutoTable — MIT, included in www/vendor/autotable-LICENSE.txt.

Bundled scripts run locally and require no CDN. Capacitor Filesystem and Share dependencies are pinned in package.json and package-lock.json.
